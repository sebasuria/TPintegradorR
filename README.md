# TPintegradorR
Entrega del Trabajo Práctico integrador del módulo de R, materia Laboratorio de Programación en Python y R, UTDT.

El script "Uria_TP_Integrador.R" contiene el código necesario para realizar todo el análisis, incluyendo la importación de la base de datos del IPC del sitio web del INDEC y las librerías necesarias. Se aclara en markdown cada sección del trabajo, así como algunos comentarios en ciertas secciones.

El documento en pdf es el informe del trabajo, describiendo la base de datos utilizada y detallando las decisiones de análisis, conteniendo además la explicación de los distintos resultados de los modelos que aparecen en R.
